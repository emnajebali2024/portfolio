## Overview

Company website of OxymedPlus built with the MERN stack, with JWT authentication and a chatbot assistant powered by the Groq API.

## What I did

- Developed the company website with MongoDB, Express.js, React.js and Node.js.
- Built REST APIs and implemented JWT-based authentication.
- Integrated an AI chatbot assistant using the Groq API.

## Technologies

MongoDB, Express.js, React.js, Node.js, JWT, Groq API
