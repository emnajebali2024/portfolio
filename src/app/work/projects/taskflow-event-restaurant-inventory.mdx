## Overview

Four management applications built during my studies: TaskFlow (Android), an event management platform (Symfony), a restaurant management system (Django) and an inventory system (Jakarta EE).

## What I did

- TaskFlow: Android application for collaborative task management and work organization (Kotlin, SQLite).
- Event management platform: web platform with separate administrator and user features (Symfony, PHP, MySQL, Bootstrap).
- Restaurant management system: CRUD operations and secure authentication for users, administrators and menus (Django, MySQL).
- Inventory management system: tracking of products, stock and inventory operations (Java, JSP/Servlets, MySQL).

## Technologies

Kotlin, Symfony, Django, Jakarta EE, MySQL, SQLite
