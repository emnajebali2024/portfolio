## Overview

Docker images for a server and a client published to Amazon ECR, built by CodePipeline and CodeBuild, scanned with Trivy and deployed on Amazon ECS.

## What I did

- Built and published the Docker images of the server and client components to Amazon ECR.
- Automated the build and delivery pipelines with AWS CodePipeline and CodeBuild, and scanned the images with Trivy.
- Deployed both components on Amazon ECS and explored blue/green deployments with AWS CodeDeploy.
- Compared pipeline executions after changes to the server and to the client code.

## Technologies

Docker, Amazon ECR, Amazon ECS, CodePipeline, CodeBuild, Trivy
