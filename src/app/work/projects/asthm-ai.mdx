## Overview

Machine learning web application that predicts asthma attacks.

## What I did

- Developed a machine learning project for the prediction of asthma attacks.
- Built the web interface with HTML5, CSS3, Bootstrap 5 and JavaScript on a Flask back end.
- Trained and served models with scikit-learn, XGBoost and joblib, with data stored through SQLAlchemy and SQLite.

## Technologies

Flask, scikit-learn, XGBoost, SQLAlchemy, SQLite, Bootstrap 5
